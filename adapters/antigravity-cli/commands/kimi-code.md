# Kimi Code

Use this command when implementation must be delegated to Kimi Code.

Required workflow:

1. Plan first with Antigravity's native model.
2. Make the plan self-contained with task, constraints, likely files, and verification commands.
3. Run `node "$HOME/.kimi-plugin/kimi-companion.mjs" code "<self-contained implementation plan>"`.
4. Do not edit implementation files directly; Kimi is the programmer.
5. Review Kimi's result, changed files, and verification before final response.
