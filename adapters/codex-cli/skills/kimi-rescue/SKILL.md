# Kimi Rescue

## Description

Delegate a coding task to Kimi CLI (Moonshot AI).

## Usage

When the user asks to delegate a task to Kimi, run:

```bash
node path/to/kimi-companion.mjs task "<task description>"
```

## Rules

- Formulate a clear, self-contained prompt.
- Run in background when possible.
- Report job ID and status to the user.
